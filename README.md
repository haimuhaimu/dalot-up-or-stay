# 达洛特：上还是不上

> **全场都在喊你上，但你身后的空间由谁来守？**

一个原创的**足球边后卫战术决策交互实验**。你将代入右后卫视角，在 10 个预设比赛片段里读取站位、空间和协防条件，再决定前插、内收、留后还是逼抢。

## 它包含什么

- **10 个预设场景**：从第 12 分钟的高位压迫，到第 89 分钟的末段抢分，覆盖领先、落后、转换与阵地战。
- **五类决策方向**：套边、内收、留后、防守站位与逼抢；具体选项会随场景变化，并非每题都有同一组答案。
- **可视化站位图**：用球员标记、危险区域和跑传路线呈现每道题的空间关系。
- **逐题复盘**：选择后立即看到得分、参考选择、战术解释、扫描重点与触发条件。
- **风格画像**：完成全部题目后，按进攻推进、防守安全、空间理解与团队协同四个维度生成结果。

## 一轮体验如何进行

1. 阅读比分、时间、阵型、球权位置与主要风险。
2. 观察站位图中的持球点、队友、对手、路线和危险空间。
3. 从当前场景给出的决策中选择处理方式。
4. 查看逐题解释；完成 10 题后获得总分、四维表现和风格画像。

## 产品边界

这是一个用于展示战术取舍的**交互实验与个人作品**，不是成熟商业产品，也不是职业训练、比赛预测或球员能力评价工具。题目、分数与解释均为作者预设的情境化观点，不代表俱乐部、球员或教练团队的官方意见。

项目不需要登录，不上传答题数据；刷新页面后即可重新开始。

## 技术实现

- React 19 + TypeScript + Vite
- 数据层定义 10 个场景、选项分数及四维影响
- 组件化实现开始、场景、选项、逐题复盘与总结界面
- 纯前端应用，无后端与数据库

## 本地运行

要求：Node.js 20.19+ 或 22.12+（以 Vite 7 的运行要求为准）。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

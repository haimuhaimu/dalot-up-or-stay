# 达洛特：上还是不上

一个使用 React、TypeScript 和 Vite 构建的足球边后卫战术决策小游戏。

玩家扮演曼联右后卫达洛特，在 10 个比赛场景中判断应该套边、内收、留后、逼抢，还是控制对手内切线路。游戏包含战术站位图、路线提示、逐题复盘和边后卫风格画像。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
